# Volta

Панель опционов: futures/options snapshots (Bybit) и overlay Polymarket.

## Быстрый старт

Из корня репозитория:

```text
cp .env.example .env
docker compose --env-file .env up --build -d
```

- Панель: [http://localhost:8081/login](http://localhost:8081/login)
- Health: [http://localhost:8081/health](http://localhost:8081/health)

Документация: [docs/README.md](docs/README.md)
